# Third-party notices and licensing status

This private development snapshot has no blanket project license. Preserve all in-tree copyright and license notices. Inclusion here does not authorize public redistribution of assets whose provenance is unresolved.

Five copied Bibata Xcursor binary payloads and unlicensed GNU reference screenshots are omitted. Cursor metadata and dependency declarations remain as source context; use an appropriately licensed external dependency only after exact provenance review. Dusk Ribbons and Moonstone Stereo's authored vector cursor builds retain their source, AUTHORS and GPL-2 license. GNU-Darwin Workstation's cursor wrapper inherits a system dependency and contains no copied native cursor payload.

Shared Island fonts: Material Symbols Rounded is Apache-2.0; Space Grotesk and NDOT47 use SIL Open Font License 1.1. Attribution is retained in components/nothing-island/applet/fonts/FONT-NOTICES.md and full texts are in licenses/. GNU GRUB PF2 fonts retain their Liberation notices and byte-provenance records under provenance/fonts/. Workstation icon notices retain their separate Window Maker and Papirus terms; no single license is substituted for these mixed sources. Moonstone's vendored MPRIS plugin retains its mpv-mpris-copyright Expat/MIT notice beside the binary. Workspace runtime retains its Cinnamon copyright and GPL-2 text.

Artwork and palette files retain their recorded source notices. Resolve any remaining author/upstream/version/license gaps before a public release or distribution to cinnamon-store as a completed theme.
