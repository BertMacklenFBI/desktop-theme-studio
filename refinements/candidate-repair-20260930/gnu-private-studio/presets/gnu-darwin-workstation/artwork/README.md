# GNU-Darwin Workstation artwork

The new wallpaper is solid palette black, matching visible uncovered pixels in the selected2002 project screenshot. No unseen wallpaper, branding, scientific documents or molecules are invented. `preview.png` is a1440×900 black wallpaper preview; `desktop/preview-static.png` is a separately labeled illustrative composition, never live evidence.

`menu-logo.png` is a lossless conversion of recovered GNUstepGlow.xpm, credited to Banlu Kemiyatorn(2000), WTFPL-1. It is Window Maker artwork from the modern Ubuntu0.96 package, not an official GNU-Darwin logo or proven identical historical screenshot bytes. Full copyright is retained in the desktop icon theme. `manifest.json` records source and output hashes.

Run `/usr/bin/python3 -B presets/gnu-darwin-workstation/artwork/generate.py` from the Studio root. No original Fastfetch artwork, shell commands, music configuration or live settings are read for mutation. The menu adapter preserves exact `le cinabon`.
