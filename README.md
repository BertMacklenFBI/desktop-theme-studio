The checks and screenshots describe the original frozen source trees in private 2880×1800 sessions. Export exclusions change five cursor payloads; those source results do not certify this snapshot as an installable release. GNU screenshots use generic test fixtures with actual host disk/resource telemetry. Historical trials and screenshots are not included as current acceptance.

Palettes, supplied artwork and retained asset bytes are preserved. Circular or pill workspace controls, readable island text, Plum's single bottom panel and Moonstone's authored receiver are included in the development work. Macintosh Soft Evergreen is outside this batch.

Browse the [acceptance scope and remaining work](docs/ACCEPTANCE.md), [source layout and dependencies](docs/DEVELOPMENT.md), [third-party notices](THIRD_PARTY_NOTICES.md), and [machine-readable status](development-status.json). [The export manifest](export-manifest.json) records every shipped file and its source digest.

Completed themes are intended for [cinnamon-store](https://github.com/BertMacklenFBI/cinnamon-store) after current release acceptance. Publication here does not enable a switch or perform installation, activation, boot or login tests.
